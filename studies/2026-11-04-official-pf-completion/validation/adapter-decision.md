# Adapter decision before any new Newton result

The original 59 inputs and native controls remain unchanged. Inspection of the exact released `closure.extract_case` at commit `517a07531ea55a11bd81a89a6c6879695a2ba4b4` found two integration issues:

1. It reconstructs admittance from float32 graph features and adds `PI_Z2_EPS=1e-12` to squared impedance. At the checked reference voltage, this differs from original-case injections by up to 0.01114 MVA on case300 and 0.002659 MVA on case500goc. These exceed the original 0.001 MW/MVAr balance tolerance and the 1e-6 MVA equation-agreement gate. Raw and prepared graph admittances match each other; this is not an unrecorded feature-cache intervention.
2. On case500goc, original angle-reference bus 311 has no online generator. The extractor retains it as a slack/control bus, so recovered slack P/Q has no permitted generator recipient. The original offline generator must remain offline. The author source's case500 matrices exactly match our preserved matrices, so this issue cannot be dismissed as the wrong network variant.

Bounded diagnostic decision, made before inspecting any new PF result: retain **both** the released graph-extraction path and an explicitly labeled **original-matrix adapter** that calls the unchanged author Newton kernel. This is a numerical/representation check on the same fixed inputs, not a new loading family or tuned model. The released path remains a separately scored outcome; it is never silently replaced by the adapter. Only a path that passes original-physics and role-mapping validation can support model-control conclusions.

The original-matrix adapter supplies the exact FP64 branch stamps, loads and shunts to the author's `Case` and unmodified `newton_pf`; it preserves all generator/branch statuses and limits. Reference/PV/PQ roles follow MATPOWER/PYPOWER `bustypes`: if no reference bus has an online generator, the first eligible PV bus becomes the balancing bus. For case500goc this changes the balancing generator and is disclosed separately from the final angle-gauge alignment. The original physical matrices are never edited, and all returned angles are aligned to original bus 311 for evaluation. No existing native prediction is recomputed with changed roles.

Primary numerical preset: published Section IV-A, 40 Newton steps, step-halving, 1e-5 p.u. tolerance (=0.001 MW/MVAr on these 100-MVA cases), cold DC angles plus the model's voltage profile. The code's final training/validation tolerance of 1e-8 p.u. (=1e-6 MW/MVAr) is a separately labeled numerical robustness check only when needed to distinguish termination tolerance from another failure. No scenario-order or AC-reference initialization is allowed.

Recovered Q is determined only at voltage-controlled buses. Multiple online generators share total Q by the conventional affine Q-range allocation, without clipping: Qmin + range * (Qtotal - sum Qmin) / sum range; zero-range groups share the required total equally. This makes per-generator Q accuracy allocation-dependent. Aggregate Q capability violations are also retained. At the balancing bus, the first online generator absorbs the active correction; other Pg controls remain fixed. These allocation conventions are explicit adapter choices because the pinned loss reports bus-aggregate Q and does not publish a per-unit allocation.

Clarification before execution: supported `bustypes` roles apply to **both** the graph-physics and original-matrix paths. An untouched-extractor reference-control check at case500goc is retained as an integration diagnostic, with unallocated slack injection visible. It is not the model comparison. This isolates the effect of graph precision/regularization while holding controls, balancing policy and initialization fixed. The main label is `V2-frozen+official-PF`; the exact-matrix diagnostic is `V2-frozen+official-PF-exact-matrix`. Both disclose the study's role/allocation adapter; neither is claimed to reproduce the missing public `evaluate_model/completion.py` exporter or target-grid training.

Known-reference controls are validation only. The reference supplies controls, never the initial unknown voltages or angles. Finite failed iterates remain failed candidates. Nonfinite/absent states have missing metrics. This study does not reproduce grid-specific fine-tuning merely by applying completion.
