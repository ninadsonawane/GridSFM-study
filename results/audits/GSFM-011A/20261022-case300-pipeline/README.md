# Experiment 11A — short pipeline-audit report

**Complete, 22 October 2026. Stopped for review.** Original case300 only; no fitting, checkpoint selection, standalone AC-PF/OPF solve, scenario sweep,11B or11C. Six forward calls verified label independence; existing feasible references and environments were reused. No installation or alteration of original data/checkpoints.

Newer base v2: source `517a07531ea55a11bd81a89a6c6879695a2ba4b4`, SHA256 `9e5333ce0573a3322432cb96c1f62031abc457299a81f66871b10232ba8ea9c7` (15,146,823 parameters). File hashes, internal checksums and strict loading passed separately. The installed Microsoft-family checkout is a Seiole fork; its exact upstream Git object was exported to temporary storage for the Microsoft row. No release was selected by performance.

2. **No solved-answer leakage was found in this path.** Features come from the unchanged source network, loads, costs/limits, original generator PG/QG/VG, and calculated topology features. Saved matrices and generator features match the pinned original input. Removing labels or replacing solution/objective blocks with two different bogus answers left all returned outputs identical. Passing a solved generator matrix as an input would still be leakage. [Loader](https://github.com/microsoft/GridSFM/blob/1ca775fd436d7ce013a1c0ab946e61ac7ef59ad6/model/gridsfm/data.py#L91), [converter](../../../../scripts/python/gridsfm_convert.py#L44).

3. **Neural scores are processed before return.** Heads produce Pg/Qg/V scores, an angle residual and a classifier logit. Raw Pg/Qg/V receive hard box clipping to stored FP32 input bounds with the shipped defaults. Angle = numerical DC prior + bounded neural residual, with an angle reference fixed. Branch-end flows are calculated from those phasors; they are not independent neural predictions. Native `predict()` runs no nonlinear AC-PF or AC-OPF. Separate newer PF completion recovers slack Pg and generator Qg, and external OPF is another stage. **Experiments9–10 used an explicit sigmoid override; it is not the newer release's shipped default.** [Microsoft output code](https://github.com/microsoft/GridSFM/blob/1ca775fd436d7ce013a1c0ab946e61ac7ef59ad6/model/gridsfm/model.py#L230), [newer output code](https://github.com/lukebhan/gridsfm/blob/517a07531ea55a11bd81a89a6c6879695a2ba4b4/model/gridsfm/model.py#L238), [historical override](../../../../experiments/gsfm007/common.py#L38).

4. **Penalties and constraints are different.** Microsoft exposes soft KCL/state/stress and rated-thermal losses; the newer fine-tuning code has separate soft elastic penalties around PF completion. Neither establishes the historical training recipe of the frozen checkpoint. Raw clipping enforces individual Pg/Qg/V boxes, not power balance or thermal feasibility. PF solves balance under its numerical operator; recovered Qg/slack Pg and PQ voltages can violate limits. External AC-OPF enforces the original coupled constraints. Flow reconstruction imposes voltage/branch consistency under its operator; cycle telescoping is not evidence that the network learned KVL. Independent flow-head consistency: **N/A**. [Every law/limit: input, loss, hard restriction and numerical enforcement](technical-audit.md#4-what-enforces-each-lawlimit).
